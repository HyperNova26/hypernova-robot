# 안전 지침

실물 장비를 다룰 때 지키는 공통 기준입니다. 기체별 hazard analysis와 시험 절차는 따로 만듭니다.

## 실물 시험 전 확인

- 물리 E-stop과 전원 차단 수단이 실제로 끊기는지 눌러 봅니다.
- 시험 책임자와 E-stop 담당자를 정합니다. 고출력 구동 시험을 혼자 하지 마세요.
- 사람과 장애물을 시험 구역 밖으로 치우고, 로봇이 갈 수 있는 범위를 표시합니다.
- 기체를 들거나 고정할 때는 하중과 구동 반력을 견디는 fixture를 씁니다.
- 배터리 전압, 전류 제한, 모터·드라이버 온도, 통신 timeout 값을 확인합니다.
- 어떤 commit과 설정, calibration, 기체 revision으로 돌렸는지 적어 둡니다.

## 단계적으로 올리기

1. 시뮬레이션과 정적 검토
2. 전원·통신만 연결한 bench test
3. 단일 구동기 test
4. 기체를 고정한 저출력 test
5. 제한된 공간의 저속 test
6. 목표 환경의 통합 test

앞 단계에서 정지와 제한 동작을 확인하지 못했다면 다음 단계로 넘어가지 않습니다.

## 즉시 중단

- 명령 없이 움직이거나, 정지 명령에 반응하지 않을 때
- 비정상 진동, 소음, 냄새, 발열, 전압 강하, 통신 불안정
- 구조물, 케이블, 배터리, 커넥터 손상
- 좌표계나 관절 방향, 제한값이 예상과 다를 때
- 사람이 시험 구역에 들어오거나, E-stop 담당자의 시야가 가릴 때

멈춘 뒤에는 전원을 분리하고 그때의 원인과 설정을 기록합니다. 원인을 설명하지 못한 채로 같은 시험을 다시 돌리지 않습니다.

## 안전 관련 변경

E-stop, watchdog, 전류·속도·관절 제한, 배터리 보호, 통신 권한을 건드리는 PR에는 안전 영향, 실패 모드, 확인 방법, 되돌리는 방법을 적습니다.
