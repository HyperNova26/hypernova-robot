# 프로젝트 범위

마지막 갱신: 2026-08-01

## 지금 만들려는 것

자율로 이동하면서 주변을 인지하고, 정해진 임무를 수행한 뒤 상태를 보고할 수 있는 로봇을 만듭니다.

## 검토 중인 범위

- 이동 플랫폼과 기체 제어
- 주변 인지, 지도 작성과 위치 추정
- waypoint 기반 임무 수행과 상태·이상 정보 전달
- 운영자 확인과 필요한 경우의 원격 개입

## 아직 정하지 않은 것

- 기체 형태와 자유도
- 센서 구성과 컴퓨팅 플랫폼
- 알고리즘, 통신 방식, 관제 UI
- 목표 성능 수치와 합격 기준
- 대외 공개 범위와 일정

## 다음에 정할 것

1. 사용 시나리오와 시험 환경을 확인 가능한 요구사항으로 정리합니다.
2. 기체, 전장, 컴퓨팅, 센서 사이의 인터페이스를 정의합니다.
3. 위험한 가정부터 작은 PoC로 확인합니다.
4. 결과를 바탕으로 시스템 구성과 패키지 구조를 정합니다.
