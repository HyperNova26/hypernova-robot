# 결정 기록 (ADR)

파일명은 `NNNN-short-title.md`. 안에는 이만큼 담습니다.

1. 상태와 날짜
2. 배경과 문제
3. 검토한 선택지
4. 결정과 그 결과
5. 다시 볼 조건
