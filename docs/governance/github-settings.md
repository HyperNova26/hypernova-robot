## 공개와 라이선스

- 저장소와 Issue, Pull Request, Actions 기록은 공개합니다.
- public 저장소이므로 누구나 fork할 수 있습니다.
- 소프트웨어 계열은 Apache-2.0, 하드웨어 설계는 CERN-OHL-S-2.0, 문서는 CC BY 4.0을 적용합니다.
- HYPERNOVA 이름, 로고와 배너는 공개 라이선스에서 제외합니다.

자세한 적용 범위는 [`LICENSE.md`](../../LICENSE.md)에서 관리합니다.

## `main` 브랜치 보호

- Pull Request 필수, 승인 1명
- force push와 브랜치 삭제 금지
- squash merge를 기본으로 사용하고 병합 후 브랜치 삭제

## Issue 라벨

- `bug`, `enhancement`, `documentation`
- `area:hardware`, `area:firmware`, `area:software`, `area:simulation`
