# GitHub 저장소 설정

## About

| 항목 | 값 |
| --- | --- |
| Repository | `HyperNova26/hypernova-robot` |
| Description | `Autonomous mobile robot project by HYPERNOVA.` |
| Topics | `robotics`, `ros2`, `student-project` |
| Social preview | 조직 프로필과 같은 HYPERNOVA banner |

기체 형태, 센서 모델, 임무 시나리오는 아직 검토 중이므로 About에 넣지 않습니다.

## 생성 전 정할 것

- 공개 범위: 초기에는 private, 공개 시점은 따로 정합니다.
- 라이선스: 소프트웨어, 하드웨어 설계, 문서·미디어에 각각 무엇을 적용할지 정합니다.
- 조직 내 maintainer

라이선스 없이 public으로 공개하면 다른 사람에게 코드를 사용·수정·배포할 권리가 생기지 않습니다. 공개 전에 정합니다.

## `main` 브랜치 보호

- Pull Request 필수, 승인 1명
- force push와 브랜치 삭제 금지
- squash merge를 기본으로 사용하고 병합 후 브랜치 삭제

## Issue 라벨

- `bug`, `enhancement`, `documentation`
- `area:hardware`, `area:firmware`, `area:software`, `area:simulation`
- `safety`
