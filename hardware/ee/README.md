# NUCLEO 실드 PCB · 1차 PoC

`feat/poc-pcb-v1` 브랜치를 받은 뒤 KiCad에서 [nucleo-shield.kicad_pro](nucleo-shield/nucleo-shield.kicad_pro)를 엽니다. 초기 상태는 빈 회로도 한 장과 빈 PCB입니다.

프로젝트 설정(`.kicad_pro`), 회로도(`.kicad_sch`), 보드(`.kicad_pcb`)를 Git으로 함께 관리합니다. 개인 화면 설정, 잠금 파일, 자동 백업은 Git에서 제외합니다.

2026-11-15 기준 KiCad 10.0.6으로 확인했습니다. 전자 설계에는 CERN-OHL-S-2.0, 이 안내에는 CC BY 4.0을 적용합니다. [라이선스 정책](../../LICENSE.md)
