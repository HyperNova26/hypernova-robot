# Simulation

로봇 모델, simulator adapter, world와 검증 시나리오를 둡니다.

- URDF/SDF/MJCF와 필요한 mesh
- 구동기·센서·접촉 모델과 parameter 근거
- 계단, 경사, 요철 같은 검증용 world
- simulation launch와 자동 평가 script
- 실기와 simulation의 차이, 알려진 한계

학습 log, checkpoint, 대규모 recording, 매 실행 결과는 커밋하지 않습니다. 기준 결과가 필요하면 요약 지표만 남기고 어떤 commit과 설정에서 나왔는지 적습니다.
